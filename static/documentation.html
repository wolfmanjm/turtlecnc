CAM Jobs Reference

Each job writes G-code for a 3-axis mill (metric, G21, absolute G90, XY plane G17). All sizes are in mm, feeds in mm/min. Depths are entered as positive numbers. Z0 is the top of the work surface unless a job says otherwise. In the drawings, the orange dashed line is the tool centre path and the blue dot is where you touch off.

Profile rectangle

Cuts the outline of a rectangle, either outside (cutting out a part) or inside (cutting a rectangular window). The path is offset by half the tool diameter so the finished rectangle is the size you entered.

Position the tool over the bottom-left corner of the rectangle (X0 Y0) before running; the job shifts to the offset start itself. Path order is +X, +Y, −X, −Y (counter-clockwise from above). Each lap steps down by one DOC, ramping down along the first X edge. At full depth the first edge is cut again to clear the ramp, then the tool lifts to Safe Z and returns to the corner.

ParameterRequiredNotes
insideyestrue = cut inside the line, false = cut outside.
widthyesX size. Must be non-zero.
lengthyesY size. Must be non-zero.
depthyes (not laser)Total depth below Z0.

Profile circle

Cuts a circle, inside or outside, as a ring of short straight segments. Put the tool at the centre of the circle. It moves to the 12 o'clock point on the offset path, plunges one DOC, and cuts a full clockwise lap, repeating until depth is reached. It then retracts to Safe Z and returns to the centre.

Inside cuts shrink the path by half the tool diameter; outside cuts grow it. An inside circle no larger than the tool is rejected.

ParameterRequiredNotes
insideyestrue = inside cut (hole/pocket), false = outside (disc).
radius or diameterone of themFinished circle size.
depthyes (not laser)Total depth below Z0.
segmentsnoNumber of straight segments. Default gives about 0.5 mm per segment; more is smoother but a longer program.

Mill hole

Mills a round hole with a helical spiral (clockwise), so a small end mill can make a larger hole. Put the tool at the centre of the hole. The tool spirals down one DOC per revolution, then does two full laps at the bottom to leave a flat floor.

If the hole is more than twice the tool diameter, the job starts with a circle of the tool's own radius and widens it by one tool diameter per pass until the final size is reached. This leaves no solid plug that could break free. The tool returns to Safe Z and to the centre afterwards.

ParameterRequiredNotes
diameteryesFinished hole size. Must be larger than the tool diameter.
depthyes (not laser)Total depth below Z0.
peckno0 = no pecking. Otherwise, after about this much depth the tool lifts to Safe Z, pauses 1 s to clear chips, and returns. A warning is written if the hole is within 1 mm of the tool size and no peck is set.

Surface wasteboard (Milltop)

Skims a flat rectangle, typically with a large surfacing cutter on a wasteboard. Touch the tool to the surface at the front-left corner and set Z0 there (the job pauses with that message). The tool centre travels the full width × length, so the cutter overhangs the edges by half its diameter.

The job plunges to the full depth in one move (the DOC setting is not used), cuts the perimeter, then rasters back and forth along X, stepping up Y each row. Keep the depth light.

ParameterRequiredNotes
widthyesX travel of the tool centre.
lengthyesY travel of the tool centre.
depthyesMaterial removed, in one pass.
stepoverno% of tool diameter between rows. Default 40.

Side mill an edge

Trims material off one edge of the stock with the side of the cutter, in light passes. You set the cutter height by hand; Z does not move. Each pass steps the cutter sideways into the edge by one DOC, skims along the edge, backs off, rapids back to the start, and returns to the edge for the next pass. The skim runs one tool diameter longer than the length so it clears the end.

The job pauses and tells you which corner to start from. Touch the cutter to the edge there. All moves are relative to that start point.

Square stock

Faces the top of a block and optionally trims its sides, using the clockwise climb-milling method from Joe Pie's YouTube videos. Touch off at the bottom-left corner of the stock, with Z0 on the top face, and set XY to zero.

The tool starts left of the stock at the top edge and cuts a row to the right, rapids (outside the stock) to the bottom edge, and cuts a row back left. Rows then work toward the middle from both sides. If a final depth is given, the pattern repeats one DOC lower until that depth is reached; with no final depth, one DOC is skimmed. The first plunge uses the plunge rate.

If a side height is given, the tool then circles the stock clockwise at that depth and trims the perimeter. The width of cut is one DOC. It approaches from the bottom-left to take up backlash.

ParameterRequiredNotes
widthyesActual X size of the stock.
lengthyesActual Y size of the stock.
heightnoDepth below Z0 to side-mill the perimeter. 0 = skip the sides.
depthnoFinal depth for facing. 0 = one DOC only.
stepoverno% of tool diameter between rows. Default 40.

Pocket

Clears a rectangular pocket to depth. Touch off at the bottom-left corner of the pocket with Z0 on the surface. Two strategies:

Spiral starts at the centre of the pocket and spirals outward, then finishes with one lap of the outline. Each level plunges at the plunge rate. Parallel starts at the corner, ramps into the outline, then cuts concentric rectangles inward. It finishes with a lap of the outline at full depth. Both go down one DOC per level and return to Safe Z and X0 Y0 at the end.

ParameterRequiredNotes
spiralyestrue = spiral out from centre, false = parallel rings from the outside in.
widthyesX size. Must be larger than the tool diameter.
lengthyesY size. Must be larger than the tool diameter.
depthyesTotal depth below Z0.
stepoverno% of tool diameter between passes. Default 40.
Always air-cut or simulate a new program before cutting, and check the touch-off instructions the program prints (MSG lines pause the machine with M0).
